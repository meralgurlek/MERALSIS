# MERALSİS YKS

APK'ya çevrilebilir Android YKS takip uygulaması.

## Özellikler
- YKS hedefi
- Ana sayfa
- TYT / AYT ders altyapısı
- Net ve deneme takibi altyapısı
- Profil
- Modern Jetpack Compose arayüzü

## Android Studio
Projeyi Android Studio ile açıp Gradle senkronizasyonundan sonra `app` modülünü çalıştırabilirsiniz.

APK: `Build > Build APK(s)`.
